# Sand Ark: Quick Mode

A 4-level browser game (about 8 minutes) teaching **Society 5.0** in construction. A concept prototype for a short mode of Sand Ark.

**Play:** `[https://<your-username>.github.io/<repo-name>/](https://xulily9.github.io/SankGame_Prototype/)` 

**Society 5.0:** Japan's vision of a human-centred society where data and AI (cyberspace) work with machines and people (physical space).

## Levels

Pick any level (recommended order 1 → 4). Each has one goal and up to 3 stars.

| Level | How to play | Society 5.0 idea |
| --- | --- | --- |
| 1. Salvage the Car | 9 moves. Drone-scan tiles, then dig for the terminal and 12 parts. | Drone site scanning |
| 2. Plan the Ark | Place 4 rooms; neighbours make links. Moving is free, building happens once. | Digital twin / BIM |
| 3. Care for the Crew | 5 turns. Set each person to Work or Rest. Get 8 repairs; nobody collapses. | Wearable sensors, worker wellbeing |
| 4. Storm Shelter | 3 days, 3 actions each. A CYBER card gives data; the next PHYSICAL card gets +50%. | Cyber–physical fusion, human–robot collaboration |

Names (Alex, Sam, Robin) are placeholders.
